## New project
This project analyzes a health care dataset that contains patient test results and other relevant attributes. The goal is to predict whether a test result is Normal, Inconclusive, or Abnormal based on the data. I explored the dataset, cleaned it, and built models to classify test results automatically.

### Dataset
* Features include things like patient demographics, medical conditions, and test-specific metrics
* Target variable: Test Result Type (Normal / Inconclusive / Abnormal)

### What I Did
* Data Exploration – checked distributions, missing values, and correlations
* Data Cleaning – handled missing values and encoded categorical variables
* Modeling – applied classification algorithms like Decision Trees, Logistic Regression, and Random Forest
* Evaluation – checked model accuracy and confusion matrix to see how well the predictions match actual results
* Insights – identified which features have the most influence on test results

### Tools
* Python, Pandas, NumPy
* Matplotlib, Seaborn
* Scikit-learn
